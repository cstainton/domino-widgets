# Explore the Domino widgets

Open the **[TeaVM showcase](https://cstainton.github.io/domino-widgets/teavm/)**
or the **[GWT showcase](https://cstainton.github.io/domino-widgets/gwt/)**.
Both galleries run the same adapted Java examples. Browse by component family,
search for a widget, or start with the forms, tables and layout examples on the home page.
The compiler link keeps you on the same example when you switch between TeaVM and GWT.

Use **Compare with upstream** on an example page to open the corresponding
[DominoKit showcase](https://dominokit.com/domino-ui/demo/v2/home).
Our examples come from the pinned `version-2` demo; the live upstream showcase
has evolved since that snapshot and includes newer and optional Pro components.
These links help you compare appearance and behaviour, rather than imply exact
parity with today's upstream release.

## Find an example

Each entry describes what you can explore, with links to both port builds and the
matching upstream page. Rendering is checked across browsers; individual interaction
coverage and known limitations are described in the [coverage guide](COMPATIBILITY.md).

## What still needs showcase coverage

The widget library sources are retained in full. A missing demonstration does not
mean its widget implementation has been omitted, but it also does not establish
that all of that widget's behaviour works on TeaVM.

The most substantial example gaps are:

- **Advanced tables:** [editing](https://dominokit.com/domino-ui/demo/v2/datatable/editable-table),
  [drag and drop](https://dominokit.com/domino-ui/demo/v2/datatable/drag-drop-plugin),
  [row grouping](https://dominokit.com/domino-ui/demo/v2/datatable/grouping-plugin),
  [record details](https://dominokit.com/domino-ui/demo/v2/datatable/record-details-plugin),
  [row menus](https://dominokit.com/domino-ui/demo/v2/datatable/row-menu-plugin),
  [scroll loading](https://dominokit.com/domino-ui/demo/v2/datatable/scroll-loading),
  [summaries](https://dominokit.com/domino-ui/demo/v2/datatable/summary-plugin),
  [top panels](https://dominokit.com/domino-ui/demo/v2/datatable/top-panel-plugin),
  [eager](https://dominokit.com/domino-ui/demo/v2/datatable/eager-tree-plugin) and
  [lazy tree grids](https://dominokit.com/domino-ui/demo/v2/datatable/lazy-tree-plugin),
  and [combined plugins](https://dominokit.com/domino-ui/demo/v2/datatable/mix-plugins).
- **Screen composition:** the original [application layout](https://dominokit.com/domino-ui/demo/v2/layout/app-layout),
  [flex layout](https://dominokit.com/domino-ui/demo/v2/layout/flex-layout),
  [grid layout](https://dominokit.com/domino-ui/demo/v2/layout/grid-layout) and complete form samples.
  The port's gallery navigation is its own small shell; it does not demonstrate the original application-layout sample.
- **Visual references:** the original [colour gallery](https://dominokit.com/domino-ui/demo/v2/colors),
  icon browser and theme examples. Included widgets already use the pinned fonts,
  icons and styles, but these dedicated reference pages have not been adapted.

The old “26 remaining” figure counts upstream **view files**, including the demo's
home page, navigation, setup, source-viewing infrastructure and login/profile screens.
It is not a count of missing widget implementations. Keep the
[complete source inventory](../reports/showcase-intake.json) for an exact file-level
account; use the examples and behaviour guide when evaluating the port.

## Practical notes

Uploads need a backend endpoint. The public GitHub Pages example cannot save files;
browser tests exercise multipart uploads against a local fixture server. Media
examples demonstrate layout and controls; playback and device permissions need
further checks.

The additional [rich text example on TeaVM](https://cstainton.github.io/domino-widgets/teavm/?page=richtext)
and [GWT](https://cstainton.github.io/domino-widgets/gwt/?page=richtext) exercises the
original editor widget, but is not extracted from an upstream showcase page.
The **Development examples** section keeps it alongside the lifecycle and native
browser fixtures, away from the public gallery's starting experience.

Read [how the examples are adapted](DESIGN.md#derive-the-showcase-from-the-original-examples)
for source provenance and build details. The widgets and original examples are the
work of DominoKit and its contributors; this gallery presents an independent port.
