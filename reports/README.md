All normal analyzer gates passed. There were no analyzer errors, missing classes or new untriaged high-priority findings. The ten existing high-priority widget findings remain explicitly accounted for in `docs/spotbugs-triage.json`. Source and Javadoc artifacts were generated by the production release build. The two build modes have identical SHA-256 manifests for all 2,025 generated Java source files.

The suite covers 51 original gallery pages and 167 extracted sample methods, plus targeted interactions and native API contracts. Gallery checks also require images to decode and resource requests to succeed. One earlier concurrent local run hit a WebKit navigation timeout; the final development run executed separately and passed without retries. Browser reports describe these final complete runs, rather than combining successful subsets.

`bundleBytes` in the summary measures uncompressed emitted JavaScript. The GWT value sums both browser permutations; an individual browser downloads one permutation. These figures are not startup benchmarks or directly equivalent download-size comparisons.

`examples/` contains independent BOM consumers for both compilers. Their local builds and six browser checks passed. The [publication workflow](https://github.com/cstainton/domino-widgets/actions/runs/34164420844) also passed: all ten artifacts deployed, both consumers built from an empty Maven repository outside the checkout, and all six external browser checks passed. `publication.json` records the tested source commit and workflow links. `hosted-verification.json` records a separate check of both public Pages showcases, including table selection and absence of browser errors.

`migration-baseline.json` retains the initial identical framework failures in the original and migrated Running Club application. These were subsequently resolved by aligning cached framework dependencies. The [migration status](../docs/MIGRATION.md) records successful full TeaVM client compilation, seven application calendar tests in Chrome and 143 matched packaged assets, with explicit limits on backend end-to-end coverage.
